# 🌐 Adaptive Portfolio — Vivek Yadav

> **An interactive developer portfolio that changes its design, tone, and visual style based on who is viewing it.**

Built with pure **HTML, CSS, and JavaScript** — no frameworks, no build tools. Every interaction, animation, and theme is hand-crafted.

## 🎯 What Makes This Different

Most portfolios show the same thing to everyone. This one adapts:

| Layer | What changes |
|---|---|
| **Age group** | Tone, messaging, hero text, stats, visual density |
| **Gender theme** | Full color palette, ornaments, layout feel |
| **Design theme** | Dark / Neon / Light / Liquid — 4 distinct visual identities |

**Total unique combinations:** 4 themes × 2 genders × 5 age groups = **40 experiences**
With the age-tone design system (youth / balanced / professional): **4 × 2 × 3 = 24 distinct visual personalities**

- **Audience Gate** — modal on first visit to select age + gender, saved to `localStorage`

## 💻 Featured Projects

### ⭐ HISAB-H — Smart Credit Management System *(Major Project — In Development)*
**Stack:** MySQL · Node.js · Express.js · JavaScript · HTML · CSS

A database-driven platform that digitizes the traditional **khata book** system for small retail shops. Customers access their credit records via a QR code and verify identity through facial authentication, replacing error-prone manual records with a transparent, automated system.

**How it works:**
1. Owner registers customers and records credit transactions in the system
2. A single QR code is displayed in the shop for all customers
3. Customer scans QR → verifies identity with facial authentication
4. Customer views outstanding balance and full transaction history
5. Customer submits payment proof (screenshot) or declares cash payment
6. Payment request stored with **Pending** status — owner verifies and confirms
7. System auto-updates outstanding balance after confirmation

**Key Features:**
- 🔐 QR code entry + facial authentication for secure customer access
- 📊 Owner dashboard with analytics, charts, and full customer list
- 💳 Payment proof upload (online) or cash declaration with verification flow
- 🤖 AI-powered **customer trust score** and **credit limit recommendations**
- 📈 Payment history analysis and trend visualization
